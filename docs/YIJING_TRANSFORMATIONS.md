# Yijing transformation algorithms

This document is the implementation contract for
`src/domain/yijing/transformations`. It describes structural operations, not interpretation.

## Canonical representation

A hexagram is the fixed tuple `[l1, l2, l3, l4, l5, l6]`, where `l1` is the bottom line and `l6`
is the top line. Each value is `yin` or `yang`. Domain functions never reverse this tuple for visual
layout; `HexagramGlyph` alone renders it top-to-bottom.

Every output tuple is resolved through `src/domain/astrology/hexagrams.ts`. A transformation must not
carry its own identity table or infer a King Wen number with arithmetic.

## Exact structural operations

For `H = [a,b,c,d,e,f]`:

| Operation               | Output                                     |
| ----------------------- | ------------------------------------------ |
| Line change for set `M` | replace each `li` in `M` with its opposite |
| Nuclear / mutual        | `[b,c,d,c,d,e]`                            |
| Line complement         | `[¬a,¬b,¬c,¬d,¬e,¬f]`                      |
| Line reversal           | `[f,e,d,c,b,a]`                            |
| Trigram exchange        | `[d,e,f,a,b,c]`                            |

Complement, reversal, and trigram exchange are involutions. The relating result changes exactly the
user-selected line positions; selecting no lines is `not-applicable`, never a guessed target.

The Hexagram 5 golden tuple is:

```text
H5             = [yang, yang, yang, yin, yang, yin]
nuclear(H5)    = [yang, yang, yin, yang, yin, yang] = H38
complement(H5) = [yin, yin, yin, yang, yin, yang]   = H35
reversal(H5)   = [yin, yang, yin, yang, yang, yang] = H6
change L1(H5)  = [yin, yang, yang, yin, yang, yin]  = H48
change L2(H5)  = [yang, yin, yang, yin, yang, yin]  = H63
change L5(H5)  = [yang, yang, yang, yin, yin, yin]  = H11
```

These vectors are executable fixtures and guard against accidental top/bottom inversion.

## Structural symmetry family

The Lab evaluates eight named operations:

```text
I, C, R, S, CR, CS, RS, CRS
```

`C` is complement, `R` reversal, and `S` trigram exchange. Composition is applied left-to-right by
the domain helper. Results are grouped by target hexagram because symmetric figures can make several
operations converge. The card retains every converging operation label. The grouping and the names
of composed operations are a **Current formalization**; individual C/R/S results retain their own
structural classification.

## Mutual Field

The traditional central nuclear result is presented beside four explicit geometric projections.
For `[a,b,c,d,e,f]`:

| Projection               | Output          | Classification        |
| ------------------------ | --------------- | --------------------- |
| Lower four-line interior | `[a,b,c,b,c,d]` | Current formalization |
| Central nuclear          | `[b,c,d,c,d,e]` | Classical structural  |
| Upper four-line interior | `[c,d,e,d,e,f]` | Current formalization |
| Lower five-line interior | `[a,b,c,c,d,e]` | Current formalization |
| Upper five-line interior | `[b,c,d,d,e,f]` | Current formalization |

“Complete Mutual Field” refers to this five-result geometric display, not to a claim that the four
additional projections are a received classical system.

## Deep Nuclear

Deep Nuclear repeatedly applies only the ordinary nuclear operation. The source signature is stored
as stage 0; each new signature is checked before continuing. Iteration stops at the first repeated
signature or at the explicit safety limit (12 by default). The result reports the repeated
hexagram, cycle start, and cycle length.

Golden path for Hexagram 5:

```text
5 → 38 → 63 → 64 → 63
```

The repeated signature begins at stage 2 and the cycle length is 2.

## Line-change destinations and paths

A six-bit mask represents changed lines. Bit 0 is line 1 at the bottom and bit 5 is line 6 at the
top. Masks 1 through 63 enumerate every non-self target exactly once. The number of destinations at
Hamming distances 1 through 6 is:

```text
6, 15, 20, 15, 6, 1
```

For a selected target with `k` differing lines, every minimal path changes each differing line once,
so the path count is `k!` (at most `6! = 720`). Paths are generated by factoradic-indexed
permutations in pages of at most 25; the application never materializes all paths merely to show a
count. Each intermediate target is resolved from the canonical source plus the lines applied so far.

## Textual and structural relations

King Wen pairs are `(1,2)`, `(3,4)`, …, `(63,64)`. Previous and next neighbors do not wrap around
at 1 or 64. These are sequence/textual relations and are not geometric transformations. A Zagua
contrast appears only when a reviewed record is supplied; no geometric partner is substituted.

Structural anatomy uses these explicit conventions:

- lines 2 and 5 are central;
- lines 1–2, 3–4, and 5–6 are Earth, Human, and Heaven;
- odd positions with yang and even positions with yin are labeled conventionally correct;
- pairs 1–4, 2–5, and 3–6 are responsive when their polarities differ.

These classifications describe structure. They do not produce a judgment, prognosis, or action.
