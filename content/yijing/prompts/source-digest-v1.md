# Source digest v1

Given one normalized source chunk and its manifest record, extract only claims supported by that
chunk. Preserve the source's own scope and terminology. Return the central dynamic, situation,
images, risks, capacities, relational implications, developmental movement, ambiguities, and
source-specific vocabulary. Every extracted item must carry the input chunk ID and source locator.

Do not synthesize across authors, repair a suspect hexagram assignment, infer missing doctrine, or
write publication prose. If identity or evidence is inadequate, return `insufficient` and explain
why. Raw excerpts produced by this step are internal research artifacts and must never enter the
public bundle.
